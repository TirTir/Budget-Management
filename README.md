# Budget-Management

### 프로젝트 소개
이 프로젝트는 개인 재정 관리를 돕기 위한 서비스로, 사용자는 본 서비스를 통해 예산을 설정하고 지출을 기록하며, 이를 기반으로 지출 컨설팅을 받을 수 있습니다. 
사용자 맞춤형 예산 설계 기능과 다양한 지출 통계를 제공하여 건강한 소비 습관을 형성할 수 있도록 지원합니다.

<br>

## 📌 주요 기능
**회원가입**

- 회원가입 시 입력된 유저 정보를 유효성 검사한 후, 데이터베이스에 저장합니다.


**로그인/로그아웃**

- `AccessToken` 및 `RefreshToken`을 Redis를 이용하여 빠르게 인증할 수 있도록 처리하며, 토큰에 적절한 TTL을 설정하여 관리합니다.
- 로그아웃 시, 남아있는 토큰을 Redis 블랙리스트에 등록하고, 해당 토큰의 유효기간 동안 접근을 차단합니다.


**예산 관리 서비스**

사용자는 카테고리별로 예산 금액과 기간을 설정할 수 있습니다.

- **카테고리별 추천 예산**
    - 사용자가 입력한 총 예산을 바탕으로, 평균적인 카테고리별 비율에 맞춰 추천 예산을 제공합니다.
    - 비율이 10% 이하인 항목들은 `기타` 항목으로 묶여서 추천됩니다.

**지출 컨설팅**

- **디스코드 알림 서비스**
    - `WebClient`를 활용하여 `Discord Webhook`에 메시지를 전송합니다.
    - 사용자가 설정한 `Discord Webhook URL`을 통해 하루 지출 컨설팅 알림을 디스코드로 전송합니다.
    - **아침 8시**에는 사용자의 지출 패턴을 분석하여 맞춤형 지출 추천 메시지를 발송합니다.
    - **저녁 8시**에는 당일 지출 내역을 기반으로 지출 가이드 메시지를 발송합니다.

- **지출 관리 서비스**
    
    사용자는 금액, 날짜, 메모, 카테고리 정보를 입력하여 지출을 등록할 수 있습니다.
    
    **지출 합계 및 카테고리별 통계 제공**
    
    - 사용자는 특정 기간 동안의 지출 내역을 조회할 수 있으며, 각 지출은 금액, 카테고리, 메모 등으로 필터링할 수 있습니다.
    - 카테고리별로 지출 금액을 그룹화하여 통계를 제공하며, 전체 지출 합계도 함께 제공됩니다.
    - 특정 지출 내역을 합계에서 제외할 수 있는 기능을 제공하여, 계산에 포함되지 않도록 처리할 수 있습니다.
    
    **지출 금액 계산**
    
    - 남은 예산 : 설정된 예산 - 지금까지 지출한 금액
    - 남은 기간 동안 사용할 수 있는 일일 지출 금액 : 남은 예산 / 남은 날짜 수
    - 최소 지출 금액 :
        - 최소 지출 금액을 보장하기 위해 1000원보다 작은 금액은 1000원으로 반올림 설정
    - 오늘 적정 금액 : 월간 예산 / 해당 월의 일수
    - 위험도 : (오늘 지출 금액 / 오늘 적정 금액) * 100

**지출 통계**

- 지난 달 대비 소비율 : (지난 달 지출 금액 / 이번 달 지출 금액) * 100
- 지난 요일 대비 소비율 : (지난 주 같은 날 지출 금액 / 이번 주 오늘 지출 금액) * 100
- 다른 사용자 대비 소비율 : (다른 사용자의 평균 소비 비율 / 내 소비 비율) * 100
